# Datos

La base de datos no se incluye en el repositorio. Es información pública del INEGI y se descarga de su sitio de datos abiertos.

- Fuente: Evaluación Cognitiva de la ENASEM 2021 (ECENASEM 2021), INEGI
- Descarga: https://www.inegi.org.mx/datosabiertos/
- Registros: 3,575

`diccionario_datos_ecenasem_2021.csv` es el diccionario de datos que acompaña a la base.

## Variables utilizadas

| Variable | Descripción |
|---|---|
| `age_mxcog_21` | Edad |
| `sex_mxcog_21` | Sexo |
| `mc_aivd_comidas_21` | Dificultad para preparar una comida caliente |
| `mc_aivd_comprar_21` | Dificultad para comprar víveres |
| `mc_aivd_medicina_21` | Dificultad para tomar medicamentos |
| `mc_aivd_dinero_21` | Dificultad para manejar dinero |
| `mc_comp_memoria_21` | Comparación de la memoria con hace dos años |
| `mc_aislado_21` | Frecuencia con que se siente aislado |
| `mc_ignorado_21` | Frecuencia con que se siente ignorado |
| `mc_falta_compa_21` | Frecuencia con que siente que le falta compañía |
| `mc_estres_21` | Estrés con relación a la pandemia de COVID-19 |
| `mc_cesd_deprimido_21` | Cinco o más síntomas depresivos CES-D (variable respuesta) |
